# AWS Amplify React+Vite Starter Project

## 🌐 Project Overview / プロジェクト概要

このリポジトリは、**React + Vite** と **AWS Amplify** を活用したモダンな Web アプリケーションのスターターテンプレートです。認証機能（Cognito）、API（AppSync）、およびデータベース（DynamoDB）といったバックエンド機能を、素早かつスケーラブルにセットアップすることを重視した構成になっています。

This template provides a foundational React application integrated with AWS Amplify, streamlined for scalability and performance.

---

## 💡 Project Background / プロジェクトの経緯

### 🏗 From Network Engineering to Cloud Native
私は現在、ネットワークエンジニアとして大規模なオンプレミス基盤の運用や機器リプレース業務に携わっています。 これまでは物理的なネットワークやハードウェアを主戦場としてきましたが、エンジニアとしての視野を広げ、次世代のインフラ構築手法を習得するため、クラウドへの挑戦を開始しました。

本プロジェクトは、AWS Amplify を使用したモダンな Web アプリケーション開発の「第1歩（First Step）」として作成したものです。 フロントエンドからバックエンドまでが高度に抽象化された Amplify のエコシステムに触れることで、インフラが「コード」や「サービス」として提供される現代のパラダイムを実体験することを目的としています。

### Learning in Native English
私は現在、プロフェッショナルな英語運用能力の向上を目指しており、英語を「第二言語」として日常的に学習しています。グローバルな技術トレンドを直接キャッチアップし、より質の高い情報に触れるため、本プロジェクトの学習および構築は、教材からドキュメントまですべて Native English の環境で実施しました。これは、将来的に国際的な環境でクラウドエンジニアとして活躍するための布石でもあります。

## 🚀 Features & Learning / 実装内容と学び

* **AWS Amplify:** ホスティングからバックエンド構築までの一気通貫なワークフローを学習。
* **Authentication (認証):** Amazon Cognito を使用した、セキュアなユーザー認証機能を標準搭載。
* **API:** AWS AppSync による、即利用可能な GraphQL エンドポイントの提供。
* **Database (データベース):** Amazon DynamoDB を活用した、リアルタイムなデータ操作が可能なデータベース基盤。
* **CI/CD Pipeline:** GitHub と連携した自動デプロイ環境の構築。
* **Modernizing Infrastructure:** 従来の EC2 ベースの管理とは異なる、サーバーレスアーキテクチャの利便性と効率性を実感しました。
